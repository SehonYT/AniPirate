## 🛠️ Technology Stack

AniPirate is built as a modern, high-performance distributed web application:

- **Frontend:** [React 18](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Tailwind CSS](https://tailwindcss.com/), [Lucide Icons](https://lucide.dev/), [Vite](https://vitejs.dev/)
- **Backend & Edge:** [Cloudflare Workers](https://workers.cloudflare.com/) (Serverless V8 isolate runtime)
- **Database:** [Cloudflare D1](https://developers.cloudflare.com/d1/) (Edge-replicated SQLite)
- **Caching & CDN:** Cloudflare Cache API with custom ETag validation (`304 Not Modified`) and Brotli/Gzip edge compression
- **Security & Privacy:** Cloudflare Turnstile, HMAC-SHA256 privacy hashing for telemetry, PBKDF2/Bcrypt password hashing, strict Content Security Policy (CSP), and automated SSRF prevention


3. **Categorization** — Tagged with supported platforms, categories, features, and safety statuses.
